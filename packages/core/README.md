# KeepNow Plugin Core

Shared API client, contracts, URL parsing, and write-up prompt used by the
official [KeepNow](https://keepnow.app) plugins for Claude Code, Codex, and Pi.

Website: [https://keepnow.app](https://keepnow.app)

This is a private workspace package and is not installed directly. Use the
README for your coding agent instead:

- [Claude Code](../claude-code/README.md)
- [Codex](../codex/README.md)
- [Pi](../pi/README.md)
